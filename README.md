# Інтерактивні вправи

Навчальні вправи, розміщені на GitHub Pages.

## Структура

Кожна вправа лежить в окремій папці з файлом `index.html`.
Головна сторінка — нейтральна заглушка без посилань, щоб із вправи не можна було перейти до інших.
Повний список вправ зберігається в окремому файлі з непередбачуваною назвою; адресу знає лише власниця.
